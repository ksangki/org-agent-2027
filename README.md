# 조직 에이전트 2027 — AI가 먼저 말을 거는 해, 조직은 무엇을 맡기고 무엇을 지키는가

> **초안 판본 (v1.0.0) — 저자가 원고 전문을 검토하기 전에 공개한 판본입니다.** 내용은 바뀔 수 있습니다.

2026년 가을, 먼저 말을 거는 에이전트가 잇달아 나오고 직원 누구나 에이전트를 만들 수 있게 됐다. 이 책은 2027년에 조직이 마주할 AX 의제를 연감 형식으로 정리한다. 개인 비서를 나눠 주는 것과 조직의 맥락·신원·승인을 가진 **조직 에이전트**를 두는 것은 무엇이 다른지, 로컬과 클라우드 사이의 처리 위치와 한국의 제도 일정은 그 결정을 어떻게 바꾸는지, 확산은 넓은데 성과는 왜 제자리인지, SaaS는 사라지는지를 의제마다 세 칸 — 2026년 10월까지 확인된 사실, 조직이 정할 것, 2027년에 대한 **가설 카드** — 으로 나눠 다룬다.

가설 카드 33장은 부록 A 「2027년 말 점검표」로 모았다. 카드마다 받아들임·범위 축소·보류·버림을 고르는 판정 칸이 있어, 독자도 자기 조직의 2027년 판단을 직접 채점할 수 있다.
